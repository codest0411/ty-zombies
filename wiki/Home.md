# 🧟 Welcome to the ty-zombies Wiki

**ty-zombies** (`tyzombie` CLI) is a fast, tactical terminal typing survival game written in Python.

## Quick Links

- **[Gameplay & Modes](Gameplay-and-Modes)** — Campaign, Endless Survival, Sentence Siege, Daily Challenge, Sandbox & Mutators
- **[CLI & Custom Packs](CLI-and-Custom-Packs)** — Command-line flags, `setup-shell`, save data, and `~/.tyzombie/packs/*.txt`

## Installation

```bash
pip install ty-zombies
# or
pipx install ty-zombies
```

Update to the latest version anytime:

```bash
pip install --upgrade ty-zombies
```
