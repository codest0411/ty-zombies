# 🎮 Gameplay & Modes

## 5 Game Modes

1. **Campaign (8 Levels)**: Escalating stages from *The Quiet Street* to *Zombie Apocalypse* with 3-star ratings and unlockable Level Select.
2. **Endless Survival**: Infinite waves with a Boss every 3rd wave.
3. **Sentence Siege (`--mode sentence`)**: Type full multi-word sentences (including spaces) and Boss Paragraphs. Build a **Word Streak**, earn `+250` **Perfect Sentence** bonuses, and gain a free power-up charge every 3 perfect sentences.
4. **Daily Challenge (`--mode daily`)**: Deterministic daily seeded run shared by date (`YYYY-MM-DD`).
5. **Sandbox & Mutators (`--mode sandbox`)**: Shareable seeds (`--seed`) + 4 toggleable mutators (`Hyper Horde`, `Glass Barricade`, `Dense Mist`, `Pure Typing`).

## Controls

| Key | Action |
|---|---|
| `a`-`z`, `space` | Lock on and type |
| `Tab` | Switch target to the next closest zombie |
| `Backspace` | Drop current target |
| `1` / `2` / `3` | Freeze / Bomb / Repair |
| `/` | Assist (lock onto closest zombie) |
| `Esc` | Pause (`M` mute/unmute, `Q` save & quit) |
